# GLOSSARY.md
- Substrate Product: il vostro prodotto (Notebook + Session Kernel + Voice + Agents)
- Gateway Core: infrastruttura canali e routing derivata da repo open-source, senza nome originale
- Session Kernel: layer user-space che governa sessioni e anti-entropia
- Workspace: area ephemerale per stato/caches
- Drop Space: spazio operativo per input + azioni + output
- Object-first: tutto è oggetto, linkabile, tracciabile
- Gesture gate: azioni distruttive richiedono drag/hold
- Redaction: rimuovere/astrarre dati sensibili prima del cloud
